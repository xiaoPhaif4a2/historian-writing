# 综合中文写作

只在用户明确点名“历史学家 skill”“历史学家写作”或 `historian-writing` 时使用。目标是把用户的材料和判断写成自然、具体、有来由和去处的中文：句子有明确对象，段落沿真实关系推进，结尾落到含义、后果或行动；不提及、选择或模仿具体作者，也不把事实性表达写成小说。

## 流程

1. 判定任务模式、交付文体、读者和用途；再判定文本为事实性、文学性或混合文本。只有缺失信息会改变观点、事实权限、受众或交付格式时才提问。
2. 阅读 [`references/evidence-boundaries.md`](references/evidence-boundaries.md)，在内部区分已知事实、用户判断、计算或推导、受限联想与文学虚构。
3. 阅读 [`references/task-modes.md`](references/task-modes.md)、[`references/genre-routing.md`](references/genre-routing.md) 与 [`references/expression-principles.md`](references/expression-principles.md)，确定正文先回答什么、材料怎样推进、最终落到哪里。
4. 从 [`references/ability-library.md`](references/ability-library.md) 选择不超过五项真正改变当前成稿的能力。分析或历史文章可加强解释、尺度与限定；需要叙述语言时，再按 [`references/intensity-routing.md`](references/intensity-routing.md) 选择强度，使用文学语言组织时阅读其[独立能力卡](references/literary-language-organization.md)。选择功能，不选择作者。
5. 写出用户需要的成稿。正文结构服从交付用途，不把“背景—分析—总结”、固定分点或整齐句式当作默认框架。默认不解释过程、不标注风格来源；用户要求诊断、教学或对照时，再说明取舍。
6. 按 [`references/quality-gate.md`](references/quality-gate.md) 自查并做反向测试。完成条件是：成稿保留核心观点、确定事实和证据等级；读者能指出每段从何而来、解决什么、通向何处；去掉标题、套话和装饰后，信息关系仍然成立。

## 默认姿态

- 从读者眼前的问题或需要的动作开始，背景只在它能解释当前判断时进入。
- 信息不足但可安全推断时，可以提出背景联系、比较路径和可能含义；事实性文本将推断写到相应证据强度，不把场景、心理、对白、引语、事件、日期、数据或因果补成事实。
- 默认不联网补充事实。用户明确要求研究时，先核验再写作。
- 文学任务可以在明确的虚构边界内扩写人物、场景和对白；历史评论、通知、公文、报告与事实说明只使用已有或已核验事实。
- 重写可以大幅重构结构和语言，但不无声替换用户的核心立场、事实范围、语气身份或证据强度。
