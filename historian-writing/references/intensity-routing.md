# 文学语言组织强度

强度由任务自动决定，不让用户选择作者或“模式”。优先按交付文体路由；用户的明确篇幅、格式与事实约束始终优先。

| 强度 | 适用任务 | 使用范围 |
| --- | --- | --- |
| 克制 | 通知、公文、报告、制度说明 | 只修复生硬衔接、重复和句子失衡；不增加场景、心理、修辞或叙事铺陈 |
| 轻量 | 未落入其他类别的写作与重写 | 调整句子长短、自然过渡和一次必要的具体—抽象转换 |
| 中度 | 评论、随笔、历史评述 | 组织叙述与评述的交替，控制叙述距离，让判断从已有材料或人物反应中生长 |
| 充分 | 用户明确要求的文学创作 | 在虚构边界内充分使用场景、人物反应、心理、叙述距离与节奏，但仍服从题材、人物和视角 |

混合文本按段落功能使用强度，不把整篇一律抬高。事实性评论即使使用中度，也只能组织已有细节和明确归属的反应；“中度”不增加事实权限。
