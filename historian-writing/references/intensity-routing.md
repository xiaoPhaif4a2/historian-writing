# 叙述与文学语言组织强度

本页只控制思想怎样取得文学形式，不负责制造观点或历史深度。先按 [`genre-routing.md`](genre-routing.md) 确定形式，再自动选择强度；用户的篇幅、事实与声音约束始终优先。

| 强度 | 适用任务 | 使用范围 |
| --- | --- | --- |
| 克制 | 历史解释、概念论述、证据密集评论 | 修复节奏、跳接和抽象悬空；判断紧贴材料，不增加叙事铺陈 |
| 轻量 | 面向公众的思想评论、短评 | 用必要的具体—抽象往返与句长变化承载问题，不用修辞替代解释 |
| 中度 | 思想随笔、个人叙述、历史人物或作品评述 | 让叙述、人物反应与评述交替，控制远近，使判断从材料中生长 |
| 充分 | 用户明确授权的文学创作 | 在虚构边界内充分使用场景、心理、对白、意象与节奏，同时保留问题、人性和社会条件 |

混合文本按段落任务调整强度。任何强度都不增加事实权限；历史纵深来自条件、机制与余波，人性重量来自欲望、选择和代价，文学形式只负责让这些关系被读者感到和理解。
