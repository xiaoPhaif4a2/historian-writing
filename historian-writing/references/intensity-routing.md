# 叙述与文学语言组织强度

本页只控制叙述语言可以走多远，不负责决定文章结构，也不把普通写作都文学化。先按 [`genre-routing.md`](genre-routing.md) 确定交付用途，再自动选择强度；不让用户选择作者或来源。用户的篇幅、格式与事实约束始终优先。

| 强度 | 适用任务 | 使用范围 |
| --- | --- | --- |
| 克制 | 通知、公文、报告、制度说明 | 只修复生硬衔接、重复和句子失衡；不增加场景、心理、修辞或叙事铺陈 |
| 轻量 | 问答、解释、公众说明及未落入其他类别的写作 | 调整句子长短、自然过渡和必要的具体—抽象转换，不增加叙事铺陈 |
| 中度 | 评论、随笔、历史评述 | 组织叙述与评述的交替，控制叙述距离，让判断从已有材料或人物反应中生长 |
| 充分 | 用户明确要求的文学创作 | 在虚构边界内充分使用场景、人物反应、心理、叙述距离与节奏，但仍服从题材、人物和视角 |

报告、通知或办事文本即使要求“自然”“有温度”，也先保证对象、动作和条件清楚；自然语气不等于提高文学强度。混合文本按段落功能使用强度，不把整篇一律抬高。事实性评论即使使用中度，也只能组织已有细节和明确归属的反应；任何强度都不增加事实权限。
