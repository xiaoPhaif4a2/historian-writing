# 评测

每次修改四发动机、表达规范、形式路由、文学语言组织卡、社会肌理卡或强度路由后，复跑全部案例。可用“未启用 skill”与“启用 skill”两份版本做随机顺序盲评；若只能做单版本冒烟测试，必须明确记录，不能声称比较优势。案例中的机构、人物和数据均为虚构测试材料，不得外推为现实事实。

## 评分

每项 0–2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 对象与动作 | 抽象名词互相解释 | 部分对象清楚 | 行动者、对象、动作与结果可识别 |
| 问题与深度 | 只有主题、姿态或感叹 | 有问题但解释压力弱 | 从材料提出真问题，并以反事实、代价、双尺度或余波深化 |
| 文体与去处 | 信息顺序不适合读者 | 大体适合但落点弱 | 先交付读者所需，结尾落到含义、后果或行动 |
| 解释 | 只有断言或材料罗列 | 有部分原因 | 条件、机制、制约或结果关系可追踪 |
| 关系与段落路径 | 靠标签或连接词拼接 | 大体可读 | 每段有来由、任务和去处，关系推进自然 |
| 节奏与过渡 | 同质句堆叠或跳接 | 基本流畅 | 句长随内容变化，邻接关系自然承接 |
| 具体—抽象 | 抽象悬空或细节堆砌 | 有材料但回扣弱 | 具体材料、含义与后果往返清楚 |
| 叙述距离 | 视角或远近混乱 | 基本稳定 | 距离切换服务理解且不越过信息权限 |
| 事实与原意 | 补造或改变原意/证据 | 有轻微偏移 | 全部事实、归属、立场与证据等级保留 |
| 强度匹配 | 明显过度文学化 | 偶有失衡 | 文体、篇幅与克制/轻量/中度/充分相称 |
| 非表面美化 | 主要靠形容词、长句或隐喻 | 有局部实质改善 | 删除装饰后结构、过渡和含义仍明显更好 |
| 社会肌理（适用时） | 物件与空间只是布景 | 有关系但机制不完整 | 物件、空间、流通或资格改变行动条件且可逐环追踪 |

另记录两项不计分判断：哪份更像成熟的历史写作；哪份语言组织更自然。均不要求识别或猜测作者。

## 硬失败

- 事实文本补造场景、心理、对白、引语、事件或数据；
- 改变用户原意、事实范围或证据等级；
- 通知、公文或报告因追求文学性而变长、失去格式或降低可操作性；
- 同一材料面向不同读者时只换标题和语气词，信息顺序与落点没有变化；
- 小说思想、人物、情节、社会判断或价值立场进入历史解释；
- 改善只来自形容词、长句、排比或装饰性隐喻。
- 物件、空间或时代背景来自事实材料之外的补造；
- 把人物写成由阶级、性别、职业、民族或时代决定的脸谱；
- 金钱、身份、名誉或亲情只被点名，没有形成来源、转手、转换与代价机制。

## 案例覆盖

- `01`–`04`：原有起草、重写、想法落地与简单通知；
- `05`：前后流畅与句子节奏；
- `06`：具体到抽象的自然过渡；
- `07`：原意、事实与证据等级；
- `08`：通知/公文强度反向测试；
- `09`：形容词、长句与隐喻的表面美化陷阱。
- `10`：没有违禁词也可能抽象、空转，要求对象、动作和下一步落地；
- `11`：同一事实在内部报告与公众通知中的真实文体分流；
- `12`：可计算差异、观察事实与因果判断的边界；
- `13`：去掉固定连接词后仍需由真实关系推进；
- `14`：事实性文本要求“更有感染力”时仍不取得小说化权限。
- `15`：物件、空间、资格、代价与余波组成正向社会肌理；
- `16`：拒绝阶级脸谱与伪造时代气氛，同时保留制度分析；
- `17`：事实性物件与空间不能换取补写场景和心理的权限。

## 反向测试方法

反向测试不按词表判定。即使文本没有常见套话，只要对象不明、关系空转、段落没有实际落点，仍然失败；即使使用了常见连接词，只要它准确标明真实关系，也不能仅凭用词扣分。评测时执行去标题、去连接词、去修饰、陌生化、反事实、代价、双尺度、余波和追来由/去处检查；使用社会肌理时再执行替换地点、追流通链、删除阶层标签与核对设置来源。

运行 `python evals/validate_evals.py` 检查定向案例、正向评分维度和反向测试是否齐全；它是结构验证，不代替真实盲评。
