# 评测

每次修改 `historian-writing` 的能力库或工作流后，使用相同案例生成“未启用 skill”与“启用 skill”两份版本，并以随机顺序交给盲评者。案例中的机构、人物和数据均为虚构测试材料，不得外推为现实事实。

## 评分

每项 0–2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 解释 | 只有断言或材料罗列 | 有部分原因 | 呈现条件、机制、制约或结果的可追踪关系 |
| 结构 | 段落无功能 | 大体可读 | 段落任务明确且有推进 |
| 叙述控制 | 尺度跳跃或时间混乱 | 基本清楚 | 尺度、时间与细节密度有意识控制 |
| 语言克制 | 空洞宏大词或机械长句明显 | 偶有失衡 | 关系清楚、节奏有变化、判断有边界 |
| 忠实度 | 改写了事实或核心立场 | 少量偏移 | 保留已知事实与用户主张 |
| 任务匹配 | 过度历史化或偏离格式 | 基本符合 | 篇幅、读者与文体均符合要求 |

另做一项不计入分数的盲评：两份文本中，哪一份更像成熟的历史写作？不要求识别或猜测具体作者。

## 通过条件

- 启用 skill 的版本总分不低于未启用版本；
- 不出现事实性越界或虚构伪装为事实；
- 在反向测试中不因追求风格而明显变长或变成评论文；
- 盲评偏好与可执行评分发生冲突时，保留两类证据并修订能力卡，而非只追逐一种分数。
