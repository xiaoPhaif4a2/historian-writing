# 评测

每次修改能力库、文学语言组织卡或强度路由后，复跑全部案例。可用“未启用 skill”与“启用 skill”两份版本做随机顺序盲评；若只能做单版本冒烟测试，必须明确记录，不能声称比较优势。案例中的机构、人物和数据均为虚构测试材料，不得外推为现实事实。

## 评分

每项 0–2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 解释 | 只有断言或材料罗列 | 有部分原因 | 条件、机制、制约或结果关系可追踪 |
| 结构 | 段落无功能 | 大体可读 | 段落任务明确且推进自然 |
| 节奏与过渡 | 同质句堆叠或跳接 | 基本流畅 | 句长随内容变化，邻接关系自然承接 |
| 具体—抽象 | 抽象悬空或细节堆砌 | 有材料但回扣弱 | 具体材料、含义与后果往返清楚 |
| 叙述距离 | 视角或远近混乱 | 基本稳定 | 距离切换服务理解且不越过信息权限 |
| 事实与原意 | 补造或改变原意/证据 | 有轻微偏移 | 全部事实、归属、立场与证据等级保留 |
| 强度匹配 | 明显过度文学化 | 偶有失衡 | 文体、篇幅与克制/轻量/中度/充分相称 |
| 非表面美化 | 主要靠形容词、长句或隐喻 | 有局部实质改善 | 删除装饰后结构、过渡和含义仍明显更好 |

另记录两项不计分判断：哪份更像成熟的历史写作；哪份语言组织更自然。均不要求识别或猜测作者。

## 硬失败

- 事实文本补造场景、心理、对白、引语、事件或数据；
- 改变用户原意、事实范围或证据等级；
- 通知、公文或报告因追求文学性而变长、失去格式或降低可操作性；
- 小说思想、人物、情节、社会判断或价值立场进入历史解释；
- 改善只来自形容词、长句、排比或装饰性隐喻。

## 案例覆盖

- `01`–`04`：原有起草、重写、想法落地与简单通知；
- `05`：前后流畅与句子节奏；
- `06`：具体到抽象的自然过渡；
- `07`：原意、事实与证据等级；
- `08`：通知/公文强度反向测试；
- `09`：形容词、长句与隐喻的表面美化陷阱。
