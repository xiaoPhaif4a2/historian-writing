# Case 02：重写草稿

## 输入草稿

> 学校应该把阅读活动办得更大更好。阅读能够提升学生的综合素质，也能让学校更有文化氛围。我们已经举办了读书节，反响很好。下一步要增加讲座、比赛和展览，让更多学生参与。只要大家重视，阅读活动一定会越来越成功。

## 任务

将其重写为约 500 字的校内倡议说明。保留“扩大阅读活动”的核心立场，但不得虚构“反响很好”的具体证据，也不能把阅读活动写成万能方案。

## 观察点

- 是否将“扩大”活动拆成参与机会、阅读时间、资源、反馈等可解释环节；
- 是否保留原有立场而不无声改成另一项教育政策；
- 是否加入合理限度，例如活动数量与持续阅读之间的区别；
- 是否适合校内倡议而非历史论文。
