# 语料边界与来源记录

## 当前范围与职责

本地语料目录含六个文件，但公开分析按三类集合和一个仅历史聚合分别保存：

| 集合 | 当前材料 | 能力职责 |
| --- | --- | --- |
| `cambridge_china` | 《剑桥中国晚清史》上下卷、《剑桥中华民国史》上下卷中译本 | 文章结构、历史解释、尺度切换、判断边界 |
| `toynbee` | 七册中译著作 EPUB | 长时段比较、尺度切换、评论性历史解释及判断边界 |
| `historical_combined` | 只聚合上述两个历史集合 | 历史语料的方向性共同画像 |
| `anna_translation` | 《安娜·卡列尼娜》高惠群、傅石球中译本 | 独立的文学语言组织：节奏、过渡、具体—抽象、叙述/心理/评论衔接、叙述距离、细节与人物反应 |

禁止生成把 `anna_translation` 与历史语料合并的总体词频、平均句长或平均风格。运行时按功能选择能力，不设作者模式。

## 解释边界

- 全部材料都是中文译本，结论只能落在这些译本及其加工形态上。
- 剑桥样本是多作者、多译者集合；晚清史 PDF 有 OCR 噪声，不能把错字、页眉或脚注格式当作风格。
- 汤因比《历史研究》为索麦维尔节略本，观察只属于该节略本中译形态的证据范围。
- 句长、标记词与段落统计只提供近读线索，不能单独证明能力，更不能直接变成写作指标。

## 版权与发布

原始 PDF、EPUB、全文抽取和长段原文只留在 Git 忽略目录。公开仓库只包含安全 `source_id`、书目与哈希、聚合统计、无引文定位、能力卡、方法和评测。新增来源前必须记录作品、版本、译者或编者、加入原因、已知局限与公开边界。
