# 路线图

## v0.1：可安装 skill

- 建立本地语料清单、提取脚本和聚合风格画像；
- 将结构、解释、叙述和语言控制写为带边界的能力卡；
- 提供起草、重写、想法落地和反向测试；
- 保证原书与全文抽取不进入 Git。

## v0.2：增量语料与评测迭代

- 在新增作者或作品时，保留来源与局限记录；
- 只将经评测改善的观察升级到核心能力；
- 扩充真实任务的匿名化评测案例。

## 远期：模型化实验（可选）

若长期评测显示指令型 skill 在明确任务上稳定失效，才评估模型化方案。届时先定义可合法使用的训练材料、基线、成本、输出质量与事实边界；没有证据表明微调优于 skill 时，不启动训练项目。
