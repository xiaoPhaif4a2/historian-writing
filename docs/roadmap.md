# 路线图

## v0.1—v0.3：既有基础（已完成）

- 建立历史语料画像、解释与尺度能力；
- 建立 Anna 独立文学语言组织画像；
- 建立事实权限、正向表达、文体与强度路由，以及原书 / 全文 Git 隔离；
- 建立正向、反向、边界与单版本冒烟评测。

## v0.4：历史—文学思想写作与社会肌理（已完成）

- 将 skill 从综合中文写作收束为历史—文学思想写作器；
- 以问题、历史、人性、语言四个发动机重组能力，并加入五项深度测试与三道硬门；
- 将《高老头》傅雷译本安全登记为独立 `balzac_translation`，限定正文边界并记录提取质量；
- 以 15 处功能性近读建立物件作证、空间设限、社会流通、欲望入制与局部—秩序连接能力卡；
- 增加社会肌理正向、脸谱化反向与事实补造边界评测；
- 支持在旧原书缺席时做受约束的增量分析，且不重算不完整历史聚合。

## 下一步：行为证据积累

- 对匿名化真实思想写作任务做多轮盲序对照，分开记录问题意识、历史解释、人性复杂度、社会肌理与语言形式；
- 增加不含显眼物件或金钱词的困难样本，检查能力能否靠关系而非关键词触发；
- 检查不同历史文化语境，确认社会肌理卡不会把 19 世纪巴黎类型化迁移为普遍判断；
- 只有跨任务稳定通过时，才把近读观察升级为更强的默认规则。

## 远期：模型化实验（可选）

只有长期评测显示指令型 skill 在明确任务上稳定失效，才评估模型化方案。先定义合法训练材料、基线、成本、输出质量与事实边界；没有证据表明模型化优于 skill 时，不启动训练项目。
