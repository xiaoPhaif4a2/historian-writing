# 路线图

## v0.1：历史写作能力（已完成）

- 建立剑桥中国史与汤因比中译语料画像；
- 将结构、解释、尺度、判断与节奏写成带边界的能力；
- 建立原书/全文 Git 隔离和自包含安装包。

## v0.2：独立文学语言组织（已完成）

- 以安全 `source_id` 和哈希目录识别语料，移除公开下载文件名；
- 将 Anna 中译本保存为独立 profile，历史聚合改名为 `historical_combined`；
- 新增文学语言组织能力卡与克制/轻量/中度/充分自动路由；
- 扩充事实边界、质量门和五类定向评测；
- 同时使用项目验证与官方 `quick_validate.py` 验证安装包。

## v0.3：综合写作内核（已完成）

- 保留 historian-writing 包名和仅显式调用边界，扩展为事实性、分析性与文学性中文写作；
- 新增对象与动作、关系承接、段落来由与去处、具体与概括等正向表达规范；
- 按通知/办事、报告/复盘、问答/解释、评论/分析、公众说明、个人叙述和文学创作进行文体路由；
- 将事实权限、文体路由、通用表达、分析能力和文学强度分层，避免把自然表达等同于小说化；
- 新增无词表空转、同材料双文体、计算与因果、连接词外壳和小说化诱惑五类反向测试。

## 下一步：行为证据积累

- 对匿名化真实任务做多轮、盲序对照，分别记录结构改善与语言组织改善；
- 只有跨任务稳定通过时，才把新的近读观察升级为核心规则；
- 若某类文体持续出现抽象空转或过度文学化，先修正正向标准或路由强度，而不是增加禁令堆积。

## 远期：模型化实验（可选）

只有长期评测显示指令型 skill 在明确任务上稳定失效，才评估模型化方案。届时先定义合法训练材料、基线、成本、输出质量与事实边界；没有证据表明模型化优于 skill 时，不启动训练项目。
