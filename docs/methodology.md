# 方法：从独立语料到四发动机能力

## 1. 安全来源目录

`analysis/source_catalog.json` 以 SHA-256 而非下载文件名识别来源。分析器遇到未登记哈希会停止；公开清单只写安全 `source_id`、书目信息、哈希、正文边界与提取质量。原书位于被忽略的 `sources_and_references/`。

完整运行要求所有登记来源在场。`--incremental` 只用于本地缺少旧原书时：它把当前来源合并进已有公开输出，保留未重算的旧画像，并拒绝只更新部分历史集合，避免污染 `historical_combined`。

## 2. 提取与正文边界

`analysis/analyze_corpus.py` 对 PDF 按页、对 EPUB 按 spine 提取。Anna 从 `text/part0009.html` 起算；《高老头》只取 `Text/chapter1.xhtml` 至 `Text/chapter6.xhtml`。全文只写入 `analysis/output/raw/`，公开输出不含原文。

清洗统一空白、排除纯页码并保留段落边界。EPUB 同时记录成员数、mimetype/CRC 状态、replacement character 与 HTML 残留，避免把提取错误当成语言信号。

## 3. 独立画像

分析器分别保存 `cambridge_china`、`toynbee`、`anna_translation` 与 `balzac_translation`。`historical_combined` 只包含两个历史集合；代码与验证器都拒绝跨历史—文学语料总体平均。统计包括文本量、单元与段落数、句长分布及小型标记表频率，只用于提出近读候选。

## 4. 功能性近读

`analysis/select_close_reading.py` 为每个安全 `source_id` 生成无引文定位。历史样本回答结构与解释问题；Anna 样本观察语言组织；《高老头》用预先声明的物件、空间、流通、资格与社会连接标记选择 15 个候选，再由人工近读判断功能。标记命中不直接升级为规则。

观察进入能力卡前必须回答：它解决什么写作问题；经何种关系起作用；何时不适用；删除修饰或阶层标签后是否仍成立；哪些人物、情节、句式、价值判断与时代类型必须留在原作。

## 5. 四发动机运行时

事实权限先区分事实、用户判断、推导、推测、感受与虚构。问题发动机从反常、冲突、隐含前提、代价或余波确定中心问题；历史发动机组织条件、变化、机制、尺度与余波；人性发动机保留欲望、约束、选择与代价；语言发动机让对象、关系、段落、节奏与叙述距离服从思想。

社会肌理不是第五发动机。物件作证主要连接语言与历史，空间设限连接历史与人性，流通链和欲望入制连接三者，局部—秩序连接负责尺度往返。运行时选择功能，不选择作者。

## 6. 评测与升级

每次修改发动机、社会肌理卡、文学语言组织或路由，都复跑正向、反向与事实边界案例。硬门检查忠实、证据 / 创作权限和反伪深刻；深度检查陌生化、反事实、代价、双尺度与余波。社会肌理另查物件/空间是否改变行动条件、流通链是否可追踪、人物是否脸谱化、设定是否越权补造。

结构验证只证明文件与覆盖存在。单版本冒烟只证明一次输出没有明显违反边界；只有多任务、盲序比较中的稳定行为证据，才能把新观察升级为核心规则。
